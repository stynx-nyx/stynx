basename and linker build ID. Its upstream v0.49.0 tag, commit and tree are ancestry,
not an assertion that this is an official Grafana release binary. CLI version
text alone is never executable identity. Preserve the upstream signature status
as unverified; source/archive byte agreement does not manufacture a tag signature.

The policy binds the complete 3,168-file source manifest, unchanged vendored
closure, patch and source producer. Only the constant-arrival-rate scheduler
changes: compute the original ordinal's due offset once; when it is at or beyond
the configured duration, return before timer reset, select, dispatch or drop;
otherwise use that same offset in the existing delay calculation. Preserve the
actual VU pool, dispatch, allocation, drop, cancellation and grace paths. No test
clock or observation seam belongs in the production binary.

The two retained Darwin arm64 builds have identical 54,863,762-byte output and
SHA-256 `8b298ebfdebe0996da23c4089055c110acb5e8f9ca23e6254bcbb1dbbe0ea12c`.
They use the exact official Go1.21.6 archive and installed file population,
separate source trees and initially empty caches, vendored dependencies, disabled
network module resolution and the bound linker flags. The retained Auditor review
accepts that reproduced **diagnostic build**, with its explicit limitations.
Read-only filesystem permissions are owner-reversible, not an immutable snapshot.
Before/after equality and reproduced bytes do not establish transient mutation

Reverify the actual acquired regular executable bytes, permissions, basename,

## Unchanged supplemental population

Select this derivative only for the additive supplemental profile. Preserve
exactly 600 scheduled target requests, 2/s for 300 seconds, two preallocated and
ten maximum VUs, one target per iteration and one measured case at a time. The
scheduler uses the original unsegmented half-open ordinal population: offsets
0, 0.5, ... 299.5 seconds are eligible; the 300-second ordinal is not scheduled.
This is a source-level finite guard before dispatch, not a JavaScript filter,
ignored extra invocation, shortened duration, replacement request or new sample
budget. Native dropped iterations remain failures. Refuse any additional engine
invocation, missing/duplicate target, interrupted window or nonzero drop count.

Preserve 30-second request timeout and completion grace, disabled connection
reuse, zero redirects/retries and all actual native timing fields. Full HTTP
latency remains blocked plus duration; connection/TLS fields are retained without
double addition. All outcomes remain in the distribution. Existing sorted linear
quantiles, strict read/write p50/p95, presign component p99 and complete endpoint,
semantic-case, quota, effect and fixture requirements remain unchanged.

The source-bound generator script and raw decoder, native counter, bounded file,
log capture and owned-process components are pinned in the policy. Use the exact
fixed CLI dialect, empty private config and closed environment it declares. Bind
actual private input paths, allocation bytes/digest and every target before
actuation. Reject CLI/config/environment overrides, execution segments, ambient
proxy/credential inputs, post-hoc script changes and arbitrary binary paths.
Final parent/runtime control closure remains a separate independent binding:
this policy does not prematurely pin a moving application manifest or producer.

The original four auth, crud, upload and cascade-delete profiles keep their

## Real calibration and later qualification

Independent test-only native instrumentation demonstrated pre-patch RED and
post-patch GREEN using the same six tests and preserved executor logic. The real
file/native HTTP component regressions and reproduced builds provide bounded
implementation evidence. They do not stand in for a real-time wire observation.

Before a real calibration, independently bind the actual source-owned launcher,
its exact Node/k6 executables, script/config/CLI/environment, raw capture/parser
closure and owned listener. Obtain actual published task admission where required
and the applicable tool/loader/process/resource custody for that component scope.
No raw receipt, source hash or true boolean supplies those facts. Retain the
Auditor's qualifications; unavailable actual admission keeps execution held.
The parent coordinates the existing authorized finite scope after these checks.

Calibration is one independently observed actual 300-second window with exactly
600 scheduled, started, completed, raw and wire targets, zero native drops and no
replacements. Preserve actual request/response identities, all eight native
timings, wall timestamps, native counters/metrics, stdout/stderr and cleanup
closure. Use actual wall/native timers; the controlled test clock cannot qualify
this observation. A simple owned local listener may prove this component only.
It supplies no AppModule, middleware, tenant/effect, provider, quota or complete
application qualification. It fills no application admission floor.

Retain genuine failures and slow/unavailable negative controls. Do not repeatedly
run until a favorable result or omit a refusal. Any follow-up requires a concrete
repair and the normal exact evidence binding. Exit zero without the full fixed
population and known owned cleanup is a refusal. Source/build acceptance and
calibration do not change any SLO or permit tuning away an observed failure.

Full application qualification additionally requires the final candidate-bound
manifest and producer/control identities, all existing native/runtime/application
