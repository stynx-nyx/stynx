# devai-main-observation

**Authority:** Architect (Constitution Article 6). Workflow edits need an Owner
`FORBID-CI-WITHOUT-ADR` receipt for the exact commit.

Reference page for `.github/workflows/devai-main-observation.yml`
("DEVAI main observation").

Authenticated DEVAI audit observation of every exact `main` SHA, bound by the GitHub Actions host adapter.

## Triggers

Pushes to `main`, and manual dispatch with `publish_observation`.

## Jobs

- `observe`: installs the exact frozen workspace with lifecycle scripts disabled, runs DEVAI doctor and `devai audit observe --as-role auditor`, uploads the observation and its provenance receipt as immutable artifacts, and attests them where GitHub supports it

## Credentials

Secret `PACKAGES_READ_TOKEN` (no fallback to the repository token); variable `DEVAI_ALLOW_OBSERVATION_PUBLICATION`.

## Notes

Package-generated by `devai init bind --host-adapter github-actions` and bound by digest in `.devai/config/github-actions-host-adapter.json`; never hand-edit it. Publishing to `refs/devai/post-merge/<sha>` needs both the dispatch input and the consent variable. Re-created by ADR-DEVAI-ADOPTION-0010.

DEVAI 2.3.2 rematerialization (ADR-DEVAI-ADOPTION-0017) aligns the checkout
and setup-node pins with the local-RC verifier and adds per-commit concurrency
without cancelling a running observation. The install uses
`pnpm install --frozen-lockfile --ignore-scripts`; observation must not depend
on lifecycle-generated repository binaries. The local-RC verifier remains 1.9.0.
