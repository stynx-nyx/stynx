# ADR-RELEASE-0006 — STYNX 3.0.0 (SM-21)

SM-21 is the one fixed-group release that carries the template-gating rows
SM-01–04, 06–08, 10 and 13–20, which the DEVAI 3.0.0 template pins (foundation
D-064). SM-05, 09, 11 and 12 gate STYNX's own adoption and may follow. The
Owner chose the version on 2026-10-22.

## Decision

1. **Version 3.0.0.** Backend packages now author and emit ESM only (SM-01), a
   breaking change, so the release is a major. 2.0.0 is skipped:
   `@stynx-nyx/angular-profile@2.0.0` is immutable non-canonical registry
   history (REGISTRY-VERSION-ANOMALY-0001) and cannot be published again. The
   canonical line moves from 1.x to 3.x. Because 2.0.0 is below 3.0.0, the
   anomaly needs no monotonicity exception for this candidate; the
   pre-publication census must still observe it exactly once, unchanged.
2. **Roster 44 → 47.** `@stynx-nyx/tsconfig`, `@stynx-nyx/eslint-config` and
   `@stynx-nyx/migration-linter` (foundation D-069) join the Changesets fixed
   group and the [package roster](../policy/stynx-package-roster.json), and
   publishable-package discovery reads `tools/` as well as `packages/` and
   `packages-web/`. The three are the roster's approved first publications:
   the census must find them absent until publication, and they carry no
   1.x history.
3. **Scope.** The closed [3.0.0 scope](../policy/release-scope-3.0.0.json)
   applies only to the uniform 47-package 3.0.0 fixed group. It keeps all
   fifteen signed local RC nodes and requires a unique successful
   exact-candidate `verified-local-rc` with independent exact-tree
   verification. No k6 or mutation tests are run: HTTP performance is
   `NOT_OBSERVED`, mutation is `NOT_RUN`, and neither promotes readiness. All
   ordinary gates stay at their existing thresholds.
4. **Two landings.** This scope, the registry policy and the release-gate code
   land first, because the required checks read them from `main`. The version
   marker `chore(stynx-workspace): version fixed group to 3.0.0` then lands as
   the first commit of its own PR, with its closed follow-up population.
5. **Publication.** Publication requires exact current `main`, a fresh
   authenticated registry and GitHub census (latest 1.6.2, rc 1.5.0-rc.2,
   3.0.0 absent for the 44 existing packages, the three first publications
   absent), the explicit full `candidate_sha` with `publish:true`, Owner
   repository opt-in, the action-specific Owner receipt for that exact `main`
   SHA, and independent checks of all 47 artifacts, integrities, tags and
   releases. A failed, partial or ambiguous publication stops recovery
   pending fresh exact Owner authorization.

## Consequences

The registry policy's prospective decision advances from 1.6.2 to 3.0.0; the
1.6.2 decision is kept as prior history. This ADR authorizes no deletion,
deprecation, replacement or dist-tag mutation of angular-profile 2.0.0, and
neither it nor the scope is a publication receipt.
